Build custom contact forms with spam protection, email notifications and entry export.

== Description ==

Form Guard lets you create unlimited contact forms with a simple drag-and-drop style field editor.

Features:

* Text, email, textarea, select and checkbox fields.
* Custom recipient email and subject per form.
* Honeypot spam protection.
* Stores all submissions in the database.
* Shortcode support: [form_guard id="your_form_id"].
* Responsive form styling out of the box.

== Installation ==

1. Upload `form-guard` to `wp-content/plugins/`.
2. Activate the plugin.
3. Go to **Tools > Form Guard** and create a form.
4. Copy the shortcode and paste it into a page or post.
